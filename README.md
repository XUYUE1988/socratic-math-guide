# Socratic Math Guide — 苏格拉底式数学问答学习法

> 不直接告诉学生答案，而是通过层层递进的提问链，引导学生自己发现规律、理解概念、攻克难题。

专为小学数学教师设计的 [WorkBuddy](https://workbuddy.cn) Skill，将苏格拉底式问答法应用于小学数学课堂。

## 核心特色

- **六层递进提问模型**：激活 → 观察 → 追问 → 辨析 → 归纳 → 迁移
- **四大教学场景**：概念引入、问题探究、错题诊断、复习巩固
- **四大领域覆盖**：数与代数、图形与几何、统计与概率、综合与实践
- **六个年级适配**：低/中/高段差异化提问策略
- **现成素材库**：四大领域×六个年级的提问链模板，拿来即用

## 安装

### 方式一：WorkBuddy Skill 安装

将 `socratic-math-guide` 文件夹复制到：
- 用户级：`~/.workbuddy/skills/socratic-math-guide/`
- 项目级：`.workbuddy/skills/socratic-math-guide/`

### 方式二：从源码使用

```bash
git clone https://github.com/你的用户名/socratic-math-guide.git
```

将 `socratic-math-guide/` 目录放入 WorkBuddy skills 路径即可。

## 使用示例

### 示例 1：概念引入 — 三年级分数初步认识

```
教师：帮我设计三年级"分数初步认识"的苏格拉底提问链

技能输出：
第1层 "过生日分蛋糕，4个人怎么分才公平？每人分多少？"
第2层 "看看1/2、1/3、1/4的图示，它们有什么共同点？"
第3层 "为什么这里要平均分？不平均分会怎样？"
第4层 "1/2和1/3哪个更大？为什么？和整数比大小一样吗？"
第5层 "能用自己的话说说什么是分数吗？"
第6层 "如果蛋糕变成8个人分，怎么表示？"
```

### 示例 2：错题诊断 — 四年级除法竖式

```
教师：学生算96÷3时把商3写在了个位，帮我设计追问链

技能输出：
第2层 "把你的竖式过程说一遍，每一步是怎么得到的？"
第3层 "这个3写在十位上，你是怎么想的？它表示什么？"
第4层 "如果3写在个位上，结果变成多少？和正确答案比一比。"
第5层 "你觉得这类题最容易错在哪一步？"
第6层 "再做这题（同类变式），这次你会注意什么？"
```

## 理论基础

| 理论 | 对应 |
|------|------|
| 苏格拉底产婆术 | 讥讽→助产→归纳 三步法 |
| 维果茨基最近发展区（ZPD） | 从已知区→最近发展区→独立解决 |
| 布鲁姆认知目标分类 | 六层递进对应记忆→理解→分析→评价→创造→应用 |
