# 提问链素材库

按小学数学四大领域 × 六个年级索引，提供现成的苏格拉底式提问链模板。

---

## 一、数与代数

### 低年级（1-2年级）

#### 一年级·10以内加减法（概念引入场景）
```
第1层 "你有5颗糖，妈妈又给你3颗，现在有几颗？用小手数一数。"
第2层 "看看这两堆（5颗和3颗），合在一起数，你发现了什么？"
第3层 "你是从5接着数的，还是从1开始数的？哪种更快？"
第5层 "如果把5和3合起来，可以用什么符号表示？"
第6层 "反过来，如果你有8颗糖，吃掉3颗，怎么算？"
```

#### 二年级·乘法初步认识（概念引入场景）
```
第1层 "教室里每排坐5个人，3排坐了多少人？你怎么算的？"
第2层 "5+5+5和5×3，它们有什么关系？"
第3层 "为什么要发明乘法？加法不够用吗？"
第4层 "5×3和3×5一样吗？画图看看。"
第5层 "什么情况下用乘法比用加法方便？"
```

### 中年级（3-4年级）

#### 三年级·分数初步认识（概念引入场景）
```
第1层 "过生日分蛋糕，4个人怎么分才公平？每人分多少？"
第2层 "看看1/2、1/3、1/4的图示，它们有什么共同点？"
第3层 "为什么这里要平均分？不平均分会怎样？"
第4层 "1/2和1/3哪个更大？为什么？和整数比大小一样吗？"
第5层 "能用自己的话说说什么是分数吗？"
第6层 "如果蛋糕变成8个人分，怎么表示？"
```

#### 四年级·除法竖式（问题探究场景）
```
第2层 "题目96÷3，先看被除数的哪一位？为什么？"
第3层 "9除以3得3，这个3写在什么位上？它表示什么？"
第4层 "如果96÷4呢？9除以4不够除怎么办？"
第5层 "能总结竖式除法从高位算起的步骤吗？"
第6层 "算856÷4，每一步都说说你的想法。"
```

### 高年级（5-6年级）

#### 五年级·方程初步（概念引入场景）
```
第1层 "天平左边放3个苹果和一个50g砝码，右边放200g砝码，天平平衡。一个苹果多重？"
第2层 "如果用x表示一个苹果的重量，怎么把天平上的关系写出来？"
第3层 "3x+50=200，这个式子告诉我们什么？"
第4层 "等式两边同时减50，天平还平衡吗？为什么？"
第5层 "什么叫做方程？方程和算式有什么区别？"
第6层 "如果天平右边放3个相同的砝码，左边放5个苹果，怎么列方程？"
```

#### 六年级·比例的意义（概念引入场景）
```
第1层 "2杯果汁配3杯水，味道怎样？4杯果汁配6杯水呢？"
第2层 "2:3和4:6，比值一样吗？它们之间有什么关系？"
第3层 "为什么比值相等的两个比，可以组成比例？"
第4层 "2:3和3:2，一样吗？比可以交换顺序吗？"
第5层 "什么样的两个比能组成比例？"
第6层 "地图上的1:50000是什么意思？实际1000米在图上是多少？"
```

## 二、图形与几何

### 低年级（1-2年级）

#### 一年级·认识图形（概念引入场景）
```
第1层 "找一找教室里哪些东西是方方的？哪些是圆圆的？"
第2层 "这些图形（长方形、三角形、圆）有什么不同？"
第3层 "你摸一摸长方形的边，和圆形的边有什么不一样？"
第5层 "长方形、三角形、圆，能各画一个吗？"
第6层 "用小棒能摆出三角形吗？能摆出圆吗？为什么？"
```

#### 二年级·长度测量（概念引入场景）
```
第1层 "你的课桌有多长？用手指量一量，再用手掌量一量。"
第2层 "你量5拃，同桌量4拃，为什么数量不一样？"
第3层 "每个人手不一样大，量的结果也不一样，怎么办？"
第5层 "尺子上的'1厘米'是什么意思？"
第6层 "量一量你的铅笔，大约几厘米？"
```

### 中年级（3-4年级）

#### 三年级·长方形周长（问题探究场景）
```
第2层 "长方形四条边的总长度叫做周长。怎么算最方便？"
第3层 "你是把四条边一条一条加起来的？有没有更快的办法？"
第4层 "（长+宽）×2 和 长+长+宽+宽 比一比，结果一样吗？"
第5层 "为什么长方形周长可以用（长+宽）×2来算？"
第6层 "正方形周长呢？它是长方形的特殊情况吗？"
```

#### 四年级·三角形内角和（概念引入场景）
```
第1层 "你见过三角形吗？画一个，量一量三个角各是多少度。"
第2层 "把三个角的度数加起来，你发现了什么？"
第3层 "每个三角形三个角加起来都一样吗？再画一个试试。"
第4层 "如果剪下三个角拼在一起，会拼成什么角？"
第5层 "能总结出三角形内角和的规律吗？"
第6层 "四边形的内角和是多少？和三角形有什么关系？"
```

### 高年级（5-6年级）

#### 五年级·圆的周长（问题探究场景）
```
第2层 "用线绕圆形物体一圈，量出线的长度，就是圆的周长。"
第3层 "周长和直径有什么关系？量大一点和小一点的圆试试。"
第4层 "周长除以直径，得到的结果大约是多少？每个圆都差不多吗？"
第5层 "圆的周长=直径×π，这里的π大约是3.14。为什么叫圆周率？"
第6层 "如果只知道半径，怎么算周长？"
```

#### 六年级·圆柱体积（概念引入场景）
```
第1层 "圆柱和长方体有什么不同？能求体积吗？"
第2层 "把圆柱切拼成近似的长方体，拼出的长方体和圆柱有什么关系？"
第3层 "长方体的底面积和高，对应圆柱的什么？"
第4层 "圆柱体积=底面积×高，和长方体体积公式一样，为什么？"
第5层 "能用公式V=Sh算圆柱体积吗？需要知道什么？"
第6层 "圆锥体积呢？它和圆柱有关系吗？"
```

## 三、统计与概率

### 中年级（3-4年级）

#### 三年级·数据收集整理（问题探究场景）
```
第1层 "班上同学最喜欢什么水果？怎么调查？"
第2层 "收集的数据怎么记录？用画'正'字的方法有什么好处？"
第3层 "画完'正'字后，怎么知道每种水果有多少人选？"
第5层 "从这张统计表里，你能看出什么信息？"
第6层 "如果要做成条形图，怎么画？"
```

### 高年级（5-6年级）

#### 五年级·平均数（概念引入场景）
```
第1层 "小明5次测验分别考了85、90、88、92、95分，你觉得他大概什么水平？"
第2层 "把5次的总分除以5，得到的数叫什么？"
第3层 "平均数和每次的实际成绩一样吗？它代表什么？"
第4层 "如果多考一次100分，平均分会怎样变？为什么？"
第5层 "平均数受什么因素影响？"
第6层 "如果一组数据：3、4、4、5、4，不用计算能猜出平均数吗？"
```

#### 六年级·扇形统计图（概念引入场景）
```
第1层 "一个班40人，喜欢语文的有8人，数学12人，英语8人，其他12人。怎么表示各占多少？"
第2层 "用条形图和扇形图表示，它们各有什么特点？"
第3层 "扇形图中，整个圆代表什么？每个扇形代表什么？"
第4层 "喜欢语文的占百分之几？和扇形的大小有什么关系？"
第5层 "扇形图最大的优点是什么？"
```
